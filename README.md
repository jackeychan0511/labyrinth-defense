# 미궁 방어대 (Labyrinth Defense) — 프로토타입

테트로미노 조각으로 **미로**를 깔아 적이 성에 닿기까지의 경로를 끊는 **경로 퍼즐 디펜스**.  
브라우저에서 바로 실행됩니다(설치·빌드 없음, 의존성 0).

## 플레이

폰·PC 브라우저에서 아래 주소를 열면 됩니다. (세로 화면)

```
https://<깃허브ID>.github.io/<저장소>/
```

## 조작

| 조작 | 동작 |
|---|---|
| 드래그 | 조각을 칸에 배치 (놓기 전 그림자 미리보기) |
| 탭 | 조각 회전 / 칸 배치 |
| 하단 칩 | 벽 내구도·대포 공격력 강화 구매 |

## 규칙

- **길을 완전히 막아도 됩니다** — 막히면 적이 벽을 부수고 뚫습니다(벽에 내구도 있음)
- 성 바로 옆 칸에도 설치 가능
- 적을 잡아 모은 **골드**로 잠긴 조각을 사고, **벽 내구도·대포 공격력**을 업그레이드
- **10웨이브 = 1스테이지** — 클리어하면 강화 상점이 열리고, 다음 스테이지는 적이 더 빠르고 단단해집니다
- 한 줄(가로/세로)을 채우면 **폭발** — 그 줄의 적 전멸
- 성 HP 5, 함락되면 런 종료 → 결과 + 최고 기록
